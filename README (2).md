# 🔍 Textile Process Detective

An interactive web application built with **Streamlit** to investigate hidden production costs, material wastage, GSM yields, and target FOB margins in apparel manufacturing.

## 🚀 Key Features
- **Material Evidence Engine:** Calculate fabric consumption automatically using GSM and surface area.
- **Cost Investigation:** Deep dive into yarn costs, dyeing, printing, stitching (CMT), trims, and overheads.
- **Multi-Currency Analysis:** Support for USD ($), EUR (€), PKR (₨), and INR (₹).
- **Interactive Visualizations:** Clear Plotly donut charts breaking down every cost component.
- **Verdict CSV Export:** Generate client-ready commercial summaries in one click.
